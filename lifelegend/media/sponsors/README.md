# Sponsor Company Logos

Drop official or custom company logo files here named by normalized brand slug:
`<brand_slug>.svg` (or `.png`, `.webp`, `.jpg`)

For example:
- `nike.svg`
- `adidas.svg`
- `emirates.svg`
- `porsche.svg`
- `ana_all_nippon_airways.svg`

Slug rule: lowercase ASCII, accents stripped, any non-alphanumeric sequence replaced by `_`.
Any brand without a logo file automatically displays clean styled monogram initials (unless overridden via the custom upload button in My Life › Sponsors).
