# My Life — Custom Image Drop-In Pack (`lifelegend/media/mylife/`)

You can replace any of the built-in SVG illustrations in **My Life** simply by dropping `.png`, `.jpg`, or `.webp` image files into this folder (`lifelegend/media/mylife/`) using the exact base filenames below (or by clicking the camera icon on any card inside the app).

- **Priority order:**
  1. Per-career image uploaded via the in-app camera button (`%APPDATA%\LiveTweet\data\careers\<careerId>\life-media\`)
  2. Global drop-in file in this folder (`lifelegend/media/mylife/<id>.png|.jpg|.webp`)
  3. Built-in editorial SVG illustration
